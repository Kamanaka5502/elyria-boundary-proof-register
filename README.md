# Elyria Systems — Boundary Proof Register

Public register of Elyria Systems boundary-proof artifacts, product corridors, evidence surfaces, and replayable governance claims.

This repository is the public index layer.

It does not contain private runtime implementation, proprietary evaluators, production enforcement logic, or operational adapters.

## Purpose

The register gives buyers, reviewers, and partners a clean map of what has been proven publicly and where each proof surface lives.

## Proof-family grammar

Elyria Systems public proof surfaces use a common grammar:

- boundary before consequence
- admissibility before execution
- receipt before persistence
- replay before trust
- refusal when invariants fail
- no hidden continuation after breach
