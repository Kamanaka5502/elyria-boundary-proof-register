# Public Proof Criteria

A public Elyria Systems proof repo must satisfy these criteria.

## Required

1. Product identity is explicit.
2. Public boundary is explicit.
3. Non-implementation status is explicit.
4. Proprietary runtime code is absent.
5. Proof vocabulary is clear.
6. Evidence or schema surface is public-safe.
7. Restricted-use terms are present.
8. VA / Veritas Aegis foundation lineage is preserved where relevant.

## Forbidden in public proof repos

- production enforcement logic
- resolver internals
- evaluator algorithms
- private thresholds or weights
- customer-specific policy configs
- operational adapters
- signing infrastructure
- exploit, intrusion, or offensive cyber tooling
- implementation pathways that clone the private system

## Acceptable

- public schemas
- redacted examples
- architecture diagrams in text
- proof vocabulary
- receipt-field descriptions
- replay-contract descriptions
- non-implementation notices
- commercial boundary statements
